## Le projet

Hastria est l'IDE agentique omega : application de bureau en Tauri/React, cœur en TypeScript/Bun, mesure partout.

- Chaque création non triviale est jugée par un modèle d'une autre famille, avec critique actionnable.
- Chaque résultat est mesuré : réussite, coût, durée, réparations, escalades.
- Chaque échec déclenche une escalade au lieu d'un abandon ; le système peut se rétracter quand il n'est pas capable.
- Le système s'améliore dans le temps, localement et par le cumul.

Multi-modèles, sessions reprenables, éditeur, diffs, terminal, approbations inline, autonomie contrôlée, stratégies s1–s14 mesurées, bench de 18 tâches à tests cachés, skills curatés, reverse, compression contextuelle, prompt enrichi.
